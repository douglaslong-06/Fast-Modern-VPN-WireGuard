## Overview

**WireGuard** — A simple, fast, and secure VPN protocol and client. It runs on **Windows, macOS, Linux, Android, iOS** and is distributed under the **GPL-2.0** license.

If you searched for *"wireguard download"*, this is the tool you are looking for. Below you will find a feature breakdown, platform-by-platform installation instructions, a quick-start example, and answers to the most common questions.

## Key Features

- Modern cryptography and tiny code base
- Very fast connection and roaming
- Simple key-based configuration
- Cross-platform clients
- Great for self-hosted VPNs
- Open source
